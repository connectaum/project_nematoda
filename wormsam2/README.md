# wormsam2 — разметка слипшихся и свернувшихся червей (SAM2)

Инструмент для рабочей станции (Windows / macOS / Linux). Бот wormbot размечает видео нематод классическим
пайплайном, но в эпизодах, где черви лежат бок о бок, пересекаются или сворачиваются в кольцо, разметки не даёт.
Для таких эпизодов бот присылает архив `episodes_<видео>.zip`; wormsam2 прогоняет его через SAM2
(видеосегментация Meta, «помни объект и веди его по кадрам») и делает `sam2_result_<видео>.zip`, который нужно
отправить боту обратно — он вольёт разметку и пересчитает кинематику.

## Установка (один раз)

Нужен интернет (скачиваются Python-пакеты ≈ 1–2 ГБ и модель ≈ 180 МБ) и 5 ГБ места на диске.

**Windows.** Распакуйте папку `wormsam2`, откройте её, щёлкните правой кнопкой по `install.ps1` → «Выполнить с
помощью PowerShell». Если Windows ругается на политику выполнения, откройте PowerShell в этой папке и введите:

    Set-ExecutionPolicy -Scope Process Bypass; .\install.ps1

Установщик сам определит, есть ли видеокарта NVIDIA (тогда ставится torch с CUDA — быстро), иначе поставит
CPU-версию (медленнее, но работает). В конце запускается самопроверка: должна напечатать `selftest OK`.

**macOS / Linux.** В Терминале:

    cd путь/к/wormsam2
    bash install.sh

На Apple Silicon используется GPU (MPS) автоматически.

Проверить, что всё на месте, можно в любой момент: `wormsam2 info`.

## Использование

1. Получите от бота `episodes_<видео>.zip`, положите его в любую папку.
2. В терминале (PowerShell на Windows) — из любой папки, установщик добавил команду в PATH
   (если терминал был открыт до установки, откройте новый):

       wormsam2 run C:\путь\episodes_IMG_8370.zip        (Windows)
       wormsam2 run /путь/episodes_IMG_8370.zip           (macOS / Linux)

   Если команда не находится: на Windows запустите `.\wormsam2.cmd …` из папки wormsam2,
   на macOS/Linux — `<папка wormsam2>/bin/wormsam2 …` (или добавьте `~/.local/bin` в PATH).

   Рядом с архивом появится `sam2_result_IMG_8370.zip`. Внутри — `epNN_overlay.mp4` и `epNN_sheet.jpg`:
   посмотрите их, чтобы убедиться, что цветные маски следуют за нужными червями.
3. Отправьте `sam2_result_<видео>.zip` боту (как файл). Он ответит обновлённой кинематикой и архивом
   `sam2_merged_<видео>.zip` с обновлённой разметкой (`labels49.npy`, `qc_frames.csv` с флагом `from_sam2`).

### Когда нужно кликать по червям

SAM2 нужно показать каждого червя на кадре, где он виден отдельно. Обычно бот делает это сам (берёт последний
«чистый» кадр каждого червя перед эпизодом). Если черви слиплись с самого начала видео и ни разу не были
видны по отдельности, инструмент откроет окно с кадром:

* стрелки ← → — листать кадры (выберите кадр, где червей можно различить глазом);
* левый клик — точка на текущем черве (2–4 точки вдоль тела), правый клик — точка «это НЕ этот червь»;
* `n` — следующий червь; `d` — удалить последнюю точку; `x` — удалить текущего червя;
* `Enter` — запустить; `Esc` — пропустить эпизод.

Точки, поставленные ботом автоматически, отмечены звёздочкой; их можно оставить как есть. Чтобы открыть
редактор для всех эпизодов принудительно: `wormsam2 run … --gui`.

### Полезные ключи

    --model tiny|small|base   модель (по умолчанию: small на GPU/Apple, tiny на CPU)
    --stride 2                обрабатывать каждый N-й кадр (черви в контакте почти не двигаются; 2–3 достаточно,
                              промежуточные кадры бот интерполирует)
    --episode 3               только эпизод №3 (можно повторять)
    --out файл.zip            куда сохранить результат

## Сколько это занимает

Скорость на кадр 1280×720: NVIDIA GPU ≈ 0,2–0,5 с, Apple M1 Pro ≈ 1,6 с (small), CPU 4–8 ядер ≈ 2–6 с (tiny).
Эпизод в 40 секунд (800 кадров) при `--stride 2` — это 400 кадров: от 2 минут на GPU до получаса на CPU.
Для каждого «кадра-подсказки» делается отдельный проход по клипу, так что два червя, показанные на разных
кадрах, удваивают время.

## Если что-то не так

* `selftest FAILED` или ошибка при установке — пришлите текст из окна установщика.
* На Apple Silicon инструмент сам выставляет `PYTORCH_ENABLE_MPS_FALLBACK=1`; если видите ошибку про MPS,
  запустите с `--model tiny` или через `CUDA_VISIBLE_DEVICES= PYTORCH_MPS=0` — на CPU.
* Маска «перепрыгнула» на другого червя — откройте эпизод с `--gui`, поставьте точки заново на кадре,
  где черви различимы, добавьте правым кликом отрицательные точки на соседе.
* Черви ни разу не были видны по отдельности — это принципиальное ограничение: показать SAM2, где чей
  червь, может только человек (клик), иначе эпизод останется без разметки.

## Что внутри

`wormsam2/sam2run.py` — обёртка над SAM2 (выбор устройства и модели, подсказки → маски по кадрам),
`midline.py` — средняя линия из маски (обходит петли и кольца), `episodes.py` — обработка архива,
`gui.py` — редактор подсказок, `cli.py` — команды. Формат обмена с ботом описан в начале `episodes.py`.
